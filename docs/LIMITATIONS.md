# 限制

Aero7 只用 Omarchy 和 Hyprland 已有的能力，不替换任何组件。下面这些 Windows 7 效果做不到，或者这一版不做。

| Windows 7 效果 | 情况 | 原因 |
|---|---|---|
| 圆形开始按钮、Windows 7 任务栏布局（大图标、窗口按钮） | 不做 | 主题只能改任务栏的颜色、透明度和大小，不能改形状。要实现需要另写一个任务栏插件（Omarchy 支持 QML 插件），属于重写组件，留到以后单独做 |
| 任务栏从上到下的渐变 | 用纯色加玻璃代替 | Omarchy 的任务栏背景只支持一种颜色加透明度；边框可以渐变 |
| 应用图标的高光和阴影 | 不做 | 需要一整套新图标 |
| 开始菜单双栏结构 | 不做 | 设计文档要求不能为了外观重写启动器；只改了颜色、玻璃和选中高亮 |
| 每个窗口的 Windows 7 标题栏和最小化、最大化、关闭按钮 | 做不到 | Hyprland 不画标题栏，各应用自己决定；设计文档也写明不能这样承诺 |
| GTK 应用整体换成 Aero 皮肤 | 不做 | Omarchy 固定用 Adwaita，只切换深浅色；另装 GTK 主题会和 Omarchy 的主题切换冲突。GTK 应用跟随浅色模式 |
| Windows 7 图标、鼠标指针 | 不做 | 原版属于微软，不能发布；没找到授权清楚的仿制品。保留 Omarchy 原样 |
| Segoe UI 字体 | 不做 | 属于微软。Omarchy 的界面字体和终端字体是同一个等宽字体，换成 Carlito 这类比例字体会让终端错位 |
| 登录界面 | 不做 | 设计文档写的是可选模块 |
| 浏览器、文档、视频窗口半透明 | 故意不做 | Windows 7 的玻璃只在窗框上，内容是不透明的；让内容透明会看不清字。Aero7 只让终端等 Omarchy 本来就半透明的窗口变成玻璃 |
| 截图里的颜色 | — | 模糊和透明会出现在截图里 |
